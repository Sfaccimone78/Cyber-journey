# Base64

## In breve
**Base64** rappresenta **dati binari grezzi** come stringhe ASCII leggibili e trasportabili — usata in HTML/CSS, data URI, allegati email e di continuo nelle sfide CTF. Non è cifratura: chiunque può decodificarla.

> [!warning] Non è Crittografia
> Base64 è un tipo di [[Encoding vs Encryption|Encoding]], non **Encryption**. Non offre alcuna riservatezza.

## Come funziona
- Ogni carattere Base64 codifica **6 bit**.
- Di conseguenza **4 caratteri** codificano **3 byte** (24 bit).

L'alfabeto usa 64 simboli: `A-Z`, `a-z`, `0-9`, `+`, `/`. Se i byte non sono multipli di 3, si aggiunge padding con `=`.

$$\text{caratteri} = \left\lceil \frac{\text{bytes}}{3} \right\rceil \times 4$$

## Esempio pratico
Convertire una stringa esadecimale in Base64 (pattern tipico CryptoHack):

```python
import base64

hex_string = '72bca9b68fc16ac7beeb8f849dca1d8a783e8acf9679bf9269f7bf'

bytes_data = bytes.fromhex(hex_string)   # hex → bytes grezzi
flag = base64.b64encode(bytes_data)      # bytes → stringa Base64

print(flag.decode('utf-8'))
```

Decodifica al volo senza codice: [[CyberChef]] (ricetta "From Base64").
