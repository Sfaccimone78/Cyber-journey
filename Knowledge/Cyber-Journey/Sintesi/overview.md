# Overview — Mappa della Wiki

Pagina radice (MOC, Map of Content). Punto di partenza per navigare la conoscenza e leggere la
**tesi in evoluzione**. L'LLM la aggiorna man mano che la wiki cresce.

## Obiettivo
Costruire una knowledge base personale per studiare **Sicurezza Informatica**, seguendo il piano
15-mesi (tronco comune Fasi 1-2 → fork Pentester / SOC Analyst).

## Aree (tronco comune)
- **Reti** — TCP/IP, DNS, HTTP/S, porte, subnetting, Wireshark · `#reti`
- **Linux** — filesystem, permessi, processi, bash, priv-esc · `#linux`
- **Windows / AD** — filesystem, utenti, Active Directory, Kerberos, Event Log · `#windows` `#ad`
- **Crittografia** — simmetrica/asimmetrica, hash, TLS · `#crypto`
- **Web / OWASP** — SQLi, XSS, IDOR, SSRF, command injection, XXE · `#web` `#owasp`
- **Tool** — Nmap, Burp, Metasploit, gobuster... · `#tool`
- **Blue Team** — SIEM, log analysis, IR, MITRE ATT&CK · `#blue-team`
- **Metodologia** — recon → enum → exploit → post-exploit → reporting · `#metodologia`

## Fondamenti CS (trasversali)
Assorbiti dalla wiki di ricerca, supportano tutte le aree:
- **Sistemi Operativi** — processi, scheduling, memoria virtuale, concorrenza, filesystem, I/O, virtualizzazione · `#os`
- **Algoritmi e Strutture Dati** — complessità, strutture dati, grafi, sorting, DP, greedy, backtracking · `#algoritmi`
